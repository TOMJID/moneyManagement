<h1 align='center'>

💰 Money Management Dashboard

</h1>

A responsive, single-page web application for personal finance tracking, built with **HTML5, Tailwind CSS, and Vanilla JavaScript**. This project provides a clean interface to monitor your balance, add or withdraw funds, and view your complete transaction history.

---

<div align='center'>

# ✨ Features

</div>

- **Fully Responsive Design**: Adapts seamlessly from mobile to desktop screens using Tailwind CSS.
- **Single-Page Application (SPA) Feel**: Navigate between Dashboard, Add Money, Withdraw, and History sections without page reloads, all handled by Vanilla JavaScript.
- **Dynamic UI Components**:
  - **Dashboard**: At-a-glance view of your current balance, a summary of account activity, and a list of recent transactions.
  - **Add & Withdraw Money**: Simple forms to deposit or withdraw funds. The application prevents withdrawals that exceed the current balance.
  - **Transaction History**: A detailed, scrollable log of all past transactions, including date, description, type, and amount.
- **Interactive Elements**:
  - Quick action buttons on the dashboard for easy navigation.
  - Smooth view transitions and hover effects for a better user experience.
- **Client-Side Logic**: All calculations and state management are handled in the browser with Vanilla JavaScript.

---

<div align='center'>

# 🛠️ Technologies Used

</div>

- **HTML5**: Semantic markup for a clean and accessible structure.
- **Tailwind CSS**: A utility-first CSS framework for rapid and responsive UI development.
- **Vanilla JavaScript**: For all DOM manipulation, event handling, and application logic.
- **Vite**: A modern frontend build tool that provides a fast development server and optimized builds.
- **Google Fonts (Playwrite DE Grund)**: For modern and readable typography.

# 🚀 Getting Started

</div>

### 1. Clone the repository

```bash
git clone https://github.com/TOMJID/moneyManagement.git
cd moneyManagement
```

### 2. Install dependencies

This will install all the necessary packages, including Vite and Tailwind CSS.

```bash
npm install
```

### 3. Run the development server

This command starts the Vite development server, usually on `http://localhost:5173`.

```bash
npm run dev
```
